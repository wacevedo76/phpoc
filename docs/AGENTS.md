# Documentation

## Purpose
Central repository for all PHPOC project documentation — format specification, planning, design, and reference artifacts.

## Ownership
- `docs/spec/` — Format specification (PHPSPEC.md)
- `docs/planning/` — Roadmaps, backlogs, and design decisions
- `docs/design/` — Architectural decisions, design goals, and workflows
- `docs/reference/` — Changelog, project map, and quick-reference material
- `docs/VISION.md` — Protocol philosophy and use cases

## Local Contracts
- Design docs are reference material, not executable specifications
- Format specification is authoritative for all implementations
- Archive of retired design docs lives in `archive/`

## Work Guidance
- Add new ADRs to `docs/design/ARCHITECTURAL_DECISIONS.md`
- Design goals live in `docs/design/DESIGN_GOALS.md`
- Workflow documents describe expected behavior, not implementation
- Update roadmaps in `docs/planning/` as milestones progress
- Add changelog entries in `docs/reference/CHANGELOG.md` on release

## Verification
None — documentation is informational, verified indirectly through test suites.
